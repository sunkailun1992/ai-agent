# AI Agent 安全编码规范

- 模型 Key、数据库密码、Nacos 凭据和 OSS 密钥不得写入代码、测试资源、脚本默认值或日志。
- Agent 不保存业务状态，不直接写主业务库。
- 患者分析输出不能替代医生诊断、治疗、用药或急救判断。
- 问卷 Agent 只返回自然提问或结构化候选答案，不直接推进问卷状态。
- 附件 URL 默认不可信，主服务必须完成鉴权和安全校验；Agent 仍要拒绝非法协议。
- 日志不得打印完整 Prompt、完整用户隐私、完整媒体 URL 或模型密钥。

## 通用日志与管理端点验证

- 升级模型 SDK、调整 DEBUG/TRACE、HTTP 调试或观测开关时，检查实际版本的日志路径，并用合成标记验证日志和标准输出不含 Prompt、指令、历史、回答正文或密钥；不能只假设 root 日志级别会屏蔽框架自行输出的敏感内容。
- Actuator health 以外的管理端点必须执行专用令牌保护；未配置令牌时失败关闭。令牌只由私有配置注入，不进入示例、日志或真实测试数据。
- 管理端点安全回归要覆盖 context/base path、规范化路径、独立管理端口和配置刷新；不能用只覆盖业务 HandlerMapping 的 MVC 拦截器替代有效保护，也不能以排障为由关闭校验。
